# Частые ошибки

## Не найден uv или Python

Откройте новый терминал после установки uv. Проверьте `uv --version`, затем из папки проекта выполните `uv sync --locked`. Для ручной установки нужен Python 3.11+; системный Python macOS может быть старее.

## Файл .command не открывает программу

Первый запуск окружения выполните из терминала. Если система сообщает об отсутствии права выполнения, из папки проекта назначьте его:

```bash
chmod +x "Avito Parser.command" "Мониторинг рынка.command"
```

Затем откройте файл снова. При ненулевом коде завершения launcher оставляет сообщение об ошибке в терминале.

## Не найден сохранённый поиск

Проверьте `uv run python avito.py list`. Имя поиска — имя файла в `searches/` без `.json`. При первом скачивании проекта личных поисков ещё нет: создайте их через меню.

## Сбор остановился или показан незавершённый обход

Сначала посмотрите ошибку в терминале, `/status` или лист «Состояние сбора». Недоступная страница, повтор страницы, изменившаяся выдача и предел обхода не считаются успешным полным сбором.

Не удаляйте базу для обычного повторного запуска: прогресс нужен для продолжения. Для очень широкой выдачи сузьте город, категорию или цену. Доступность внешнего источника не проверяется офлайн-тестами.

## Нет выгодных предложений

Это не обязательно ошибка. Проверьте количество аналогов, город, продавца, полноту характеристик и состояние товара. По умолчанию требуются пять других аналогов, разница 15% и 3 000 ₽. Неподдерживаемые категории не получают полноценную автоматическую оценку.

## Excel не обновляется

Закройте книгу в Excel и повторите `uv run python avito.py table my-search`. Посмотрите ошибку выгрузки в терминале: открытая книга может запрещать замену файла. Объявления и история сохраняются в SQLite отдельно от отчёта.

## Telegram не присылает сообщения

Проверьте настройку через меню, привязанный чат и наличие подходящих предложений. Просмотр кнопок работает при запущенном мониторинге. Один бот рассчитан на один одновременно работающий процесс. Параметр `--no-telegram` отключает отправку.

Не публикуйте токен в Issue. Настройки лежат в `data/telegram.json`, переменная `AVITO_TELEGRAM_TOKEN` имеет приоритет над сохранённым токеном.

## Перенос на другой компьютер

1. Остановите мониторинг через Ctrl+C.
2. Отдельно скопируйте свои `searches/` и `data/` надёжным способом.
3. На новом компьютере скачайте код и заново создайте Python-окружение.

Не переносите `.venv` между разными системами. Вместе с SQLite могут потребоваться файлы `-wal` и `-shm`. Личные данные и настройки намеренно не находятся в GitHub-репозитории.
