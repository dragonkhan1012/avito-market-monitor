# Мониторинг выгодных предложений

Откройте «Мониторинг рынка.command» и оставьте окно работающим. Оно запустит все
сохранённые поиски с профилем `goods`. «Avito Parser.command» открывает обычное
меню, где можно выбрать отдельный поиск и скорость. Сон компьютера и закрытие
окна приостанавливают работу. После нового запуска обработка продолжается.

## Просмотр в Telegram

Подключите бот через меню → Telegram. Пока работает мониторинг:

- `/start` или `/deals` — кнопки активных поисков;
- `/searches` — тот же список;
- `/status` — прогресс страниц, очередь описаний, ошибки и уведомления.

Выберите поиск. Вы получите до пяти предложений на странице с ценой, обычной
ценой похожих товаров, числом аналогов и кнопкой «Открыть на Авито». Кнопки
«Далее», «Назад» и «Обновить» работают по сохранённой базе. Бот не запускает
новый сбор при каждом нажатии. Посторонние чаты не получают данные.
Один бот обслуживает один одновременно запущенный процесс мониторинга.

## Как выбираются товары

Для поиска MacBook Pro 13 2020 программа отличает Air от Pro, Intel от
Apple M1, разные объёмы памяти и накопителя. Она читает заголовок, начало
описания и явно подписанные характеристики. Данные из поискового запроса не
подставляются вместо отсутствующих характеристик объявления. Если данные
противоречат друг другу, товар остаётся для ручной проверки.

Универсального справочника любых товаров в проекте нет. Автоматическая оценка
реализована для MacBook и iPhone; прочие категории сохраняются с пометкой о
необходимости отдельного правила сравнения. Для Intel требуется точная модель
процессора. Состояние определяется по тексту продавца и требует личной проверки.
У iPhone региональные версии и тип SIM отдельно не оцениваются.

Обычная цена — середина цен других похожих предложений в том же городе.
Сам оцениваемый товар исключается из списка. Явные неисправности, предложения
только с доставкой и крайности за пределами 50–180% предварительной обычной
цены не используются как аналоги. При большом разбросе оценка не выдаётся.
Если включены только частники, магазины не используются и в качестве аналогов.

По умолчанию для отметки «выгодно» нужны одновременно:

1. Не менее пяти других похожих предложений.
2. Цена ниже обычной минимум на 15% и минимум на 3 000 ₽.
3. Подходящие город и продавец, отсутствие явных признаков неисправности.
4. Цена не ниже половины обычной: такие случаи выделяются как подозрительные.

Это сравнение запрашиваемых цен, а не подтверждённых сделок. Батарея, ремонт,
комплект, фактическое состояние и достоверность описания влияют на покупку.
Если полное описание ещё не удалось прочитать, это указано в заметках.

## Полнота сбора и повторы

Сначала страница сохраняется в SQLite, затем анализируется. Ошибка отдельного
объявления оставляет исходные данные в базе и видна в состоянии сбора.
Следующий цикл анализирует его снова. Проблемная страница не пропускается:
мониторинг повторяет её с увеличением паузы до 15 минут.

На каждой итерации обход продвигается дальше; первая страница дополнительно
проверяется между глубокими страницами. `watch_pages` задаёт число страниц
обхода за цикл, а не постоянное ограничение первыми страницами.

Если доступная выдача пройдена и число уникальных объявлений сходится с тем,
что сообщил источник, проход отмечается завершённым. После этого начинается
новый. Если выдача изменилась, пришла одинаковая страница или достигнут предел
100 страниц, это не считается полным сбором. Для слишком больших поисков
нужно сузить фильтры. `scan` делает конечный проход с тремя попытками страницы;
`watch` продолжает повторять работу до остановки.

Полные описания загружаются по очереди, по два за цикл. Новые и изменившиеся
объявления снова ставятся на чтение; неизменившиеся описания обновляются раз
в сутки. После основного `scan` программа дочитывает доступные описания.
Недоступные страницы остаются в очереди с паузой для следующей попытки.

Объявления не удаляются из истории. После отсутствия в двух завершённых
проходах они исключаются из текущих предложений. Также не используются
объявления, которые не встречались в выдаче более семи дней.

Источник может скрыть объявление, ограничить выдачу или удалить товар между
запросами. Поэтому программа показывает полноту доступного обхода, а не
обещает обнаружить объявления, которых источник не отдавал.

## Настройки поиска

В `searches/<имя>.json` можно добавить следующие поля, сохранив остальные:

```json
{
  "min_analogs": 5,
  "deal_discount": 0.15,
  "deal_min_saving": 3000,
  "market_max_age_days": 7,
  "watch_pages": 1,
  "details_per_cycle": 2,
  "export_interval": 900,
  "alert_sellers": "private"
}
```

`deal_discount` — доля: 0.15 означает 15%. `export_interval` — секунды.
Минимум аналогов можно уменьшить до трёх, но оценка станет менее устойчивой.
`alert_sellers: "all"` включает компании. Старые параметры `fresh_hours` и
`new_only` продолжают действовать для недвижимости; товары оцениваются по
актуальности наблюдения и выгодности, включая снижение цены у старого товара.

## Файлы и восстановление

- `data/searches/<имя>/market.sqlite` — объявления, результаты, история,
  прогресс и очередь отправки; вместе с ним могут существовать файлы `-wal` и `-shm`.
- `listings.json`, `seen.json`, `state.json` — совместимые копии данных.
- `output/<имя>-monitor.xlsx` — один обновляемый Excel для поиска.
- `data/telegram.json` — секретный токен и подключённый чат.

Перед копированием базы закройте мониторинг. Блокировка не позволяет двум
процессам одновременно менять один поиск. Обновление Excel делается через
временный файл; если Excel запрещает замену открытой книги, база продолжает
работать, а ошибка выгрузки будет показана.

Очередь отправки сохраняется после сетевой ошибки. Успешная отправка помечается
в базе. При аварии между отправкой и сохранением подтверждения Telegram
возможно повторное сообщение: API не даёт гарантии строго однократной доставки.

## Проверка без Авито и Telegram

```bash
uv run --extra test python -m pytest -q test_market_monitor.py test_watch_alerts.py test_goods.py test_cli.py test_menu.py test_apartments.py test_item_page.py test_link_resolver.py test_watch_pacing.py
```

Новые проверки используют временные базы и подставные ответы; настоящие
уведомления и запросы к объявлениям при них не отправляются.
