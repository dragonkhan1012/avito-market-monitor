# Разработка и предложения

## Локальная проверка

```bash
uv sync --locked --extra test
uv run --extra test python -m pytest -q
uv run python avito.py --help
uv run python avito.py --json list
```

Проверки бизнес-логики используют временные базы и подставные ответы. Live-сценарий не должен автоматически запускаться в CI или отправлять Telegram-сообщения.

## Сообщение об ошибке

В Issue укажите систему, версию Python, команду запуска, ожидаемый и фактический результат. Для ошибки отчёта опишите проблемную колонку или правило сравнения.

Перед приложением лога удалите токены, cookies, адреса прокси с паролями, Telegram chat ID и сведения о чужих аккаунтах. Не прикладывайте `data/telegram.json`, базы объявлений и полные HAR-файлы.

## Изменение кода

- Опишите пользовательскую проблему, которую решает изменение.
- Для хранения сохраняйте совместимость баз или добавляйте явную миграцию.
- Для нового правила определения товара добавляйте положительные, отрицательные и неполные примеры.
- Сохраняйте уведомления и историю цен после ошибок и перезапуска.
- Не добавляйте настоящие объявления, персональные конфигурации и секреты в тестовые фикстуры.

Лицензии сторонних компонентов и уведомления об авторских правах должны сохраняться.
